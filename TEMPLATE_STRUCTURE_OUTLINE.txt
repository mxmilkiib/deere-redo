MIXXX DEERE-REDO SKIN: XML TEMPLATE INCLUSION STRUCTURE
========================================================

Accurate, verified hierarchy derived from reading the actual XML files.
Templates expand inline: each <Template src="..."/> inserts its children
directly into the parent layout as siblings (not wrapped in an extra node).
Singletons are defined once and referenced by name elsewhere.

Last verified: 2026-05-13

// MARK: SPACING RULES
// -- how gaps are set

Spacing philosophy:
- ControlsRow inter-group gaps: explicit <WidgetGroup><Size>2,0</Size></WidgetGroup>
  spacers between each template group; qproperty-layoutSpacing: 0 on ControlsRow.
  Edge centering via <Size>4f,0</Size> flex spacers at each end.
- HotcueGrid row button gaps: #HotcueGrid { qproperty-layoutSpacing: 2; } in QSS
  (specificity 10) overrides global WWidgetGroup { qproperty-layoutSpacing: 0; } (specificity 1).
- Vertical row gaps in DeckRows: global WWidgetGroup { qproperty-layoutSpacing: 0; }
  baseline. Current margins: #OverviewRow { margin: 0; }, #ControlsRow { margin-top: 2px;
  padding-bottom: 1px; }. #DeckRows > WWidgetGroup { qproperty-layoutAlignment: 'AlignTop
  | AlignHCenter'; } pins each row to the top of its allocated space.
- Per-group alignment: AlignLeft | AlignTop on #LoopControlsSimple, #LoopGrid,
  #LoopGridTop, #LoopGridBottom, #BeatjumpContainer, #HotcueGridContainer, #OverviewRow
  — pins button content to top-left within each container.
- MaximumSize caps: all control groups have natural-content-width MaximumSize values
  to prevent unbounded expansion on wide/HiDPI displays.
- Inner button group gaps (loop, beatjump): explicit <Size>2,0</Size> spacer WGs
  between buttons within each row; containing WG layoutSpacing stays at 0.

Key config keys driving visibility:
- [Skin],show_4decks          → deck 3 and 4 visibility
- [Skin],show_intro_outro_cues → SpecialCuesContainer / OutroCuesContainer
- [Skin],hotcue_count          → which hotcue grid (0-4) is visible
- [Skin],show_loop_hotcues     → LoopGrid (16-beatloop grid) visibility
- [Skin],show_effectrack       → entire effect rack
- [Skin],show_coverart         → spinny vs cover art widget in visual row
- [Deere],show_parallel_waveforms → parallel vs per-deck waveform display
